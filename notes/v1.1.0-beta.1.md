The reader becomes a simple markdown editor.

- Files open formatted and editable (WYSIWYG), with a formatting toolbar: text style, bold, italic, strikethrough, code,
  link, lists, task lists, quotes, code blocks, tables, images and horizontal lines
- Markdown typed as you go is applied right away (`## `, `- `, `1. `, `> `, `**bold**`, `` `code` `` …)
- Markdown mode (Ctrl+E): the raw text with a live preview; the toolbar works there too
- Tabs moved to the title bar like in Notepad; drag them to reorder. Closing the last tab leaves an empty document
- Ctrl+click follows links; Ctrl+K adds one; task checkboxes toggle with a click
- Front matter, HTML, footnotes and reference links are kept when saving from the visual editor. Files the visual
  editor can't keep exactly, and files over 1 MB, open in Markdown mode
- Sessions from earlier versions are restored (split-view tabs open in Markdown mode)
