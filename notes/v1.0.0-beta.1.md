First release.

- Opens markdown files rendered (GitHub-flavored: tables, task lists, code highlighting, images)
- Edit mode with a live preview side by side
- Tabs in a collapsible sidebar; reopen closed tabs with Ctrl+T
- Open tabs and unsaved changes survive a restart, like Notepad
- Follows changes made to open files by other programs
- Light and dark theme
- Portable, with updates from GitHub releases
